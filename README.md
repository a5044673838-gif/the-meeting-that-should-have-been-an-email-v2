Entry for make.fun's "The Meeting That Should Have Been an Email" bounty: the single sentence that could have replaced an entire pointless meeting. Replacement entry (v2) — one line, 140 characters.

> After 47 minutes, nine people agreed the meeting should have been an email — then stayed twenty more minutes arguing over who would send it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

The program writes the entry line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Python standard library only, no network.
